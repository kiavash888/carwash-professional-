# Khodkar | CarwashYab Platform

نسخه جدید با برند خودکار:
- فونت فارسی Vazirmatn
- طراحی مدرن‌تر
- کارواش‌یاب
- پمپ بنزین‌ها
- جایگاه شارژ خودرو برقی
- پنل مدیریت `/admin`
- API آماده رزرو
- Supabase schema
- آماده اتصال زرین‌پال

## Deploy
فایل‌ها را جایگزین پروژه قبلی کن، در GitHub Desktop Commit و Push بزن. Vercel خودکار آپدیت می‌شود.
